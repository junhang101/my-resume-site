ONGOING RESEARCH

Explainable Social Network Analysis for E-Commerce Customer Insights

This project focuses on analysing customer relationships in e-commerce environments using Social Network Analysis (SNA). It aims to identify customer connections, communities and influential customers while providing understandable explanations for the analytical results.

Research Objectives

  • To analyse customer relationships using Social Network Analysis.
  • To identify important customers and communities within the network.
  • To provide explainable insights that help users understand analytical results.

Research Methods and Techniques

Social Network Analysis Degree Centrality Betweenness Centrality Closeness Centrality Louvain Community Detection SHAP LIME

Expected Outcome

A software-based system that presents customer network analysis results with explanations to improve the interpretability of e-commerce customer insights.

Status: In Progress
